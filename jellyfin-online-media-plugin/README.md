# Online Media Jellyfin plugin

Targets Jellyfin 12.1 / .NET 10. Build with `./build.sh` or `dotnet build -c Release`; the script installs the DLL into `../deploy/plugins/OnlineMedia/` for the Compose mount. Restart Jellyfin after copying. Configure the HTTPS Media API Base URL and API Key in Dashboard → Plugins → Online Media. `Channels/OnlineChannel.cs` implements the public `IChannel` and `IRequiresMediaInfoCallback` interfaces. `Services/MediaApiClient.cs` reuses one connection pool, applies configuration and cancellation, and wraps API errors. The Channel shows Library, Featured, and labeled Search Examples. There is no Jellyfin global text search integration. The plugin does not parse Internet Archive or manage a database.
